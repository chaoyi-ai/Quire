# Typora 调研（2026-08，Typora 1.14）

> 目的：为 M6 定方向。Typora 是"混合实时预览"Markdown 编辑器的标杆（$14.99，Electron，官网 typora.io）。
> 方法：浏览 typora.io 首页功能展示图 / 视频、support.typora.io 全部文档索引、1.13 / 1.14 更新日志、主题站。
> 结论先行：**Typora 赢在"写"的体验（所见即所得 + 表格/图片/数学的就地编辑）和"文件工作台"（快速打开、全局搜索、字数、专注模式）；Quire 赢在"读"（原生 TextKit 2、1 MB 文档 170 ms、40 MB 内存、零空闲 CPU）。M6 不做 Typora 克隆，只补"写"和"工作台"里性价比最高的部分，继续不用 WebView 渲染正文。**

## 1. 观察到的交互细节（从官方演示图逐张看）

| 场景 | Typora 的做法 | 对 Quire 的启发 |
|---|---|---|
| 图片 | 光标在图片段落上时，上方显示一行灰色等宽源码 `![winter](/img/…)`，图片仍渲染在下方；离开后源码收起 | 混合模式的"当前块显源码"不是把块整个替换成源码，而是**源码 + 渲染同时可见**（块级元素尤其如此：图片、表格、数学、Mermaid） |
| 表格 | 输入 `|item|Qty|Price|` 回车即生成表格；单元格直接在渲染态里编辑；拖列宽、拖行列重排；单元格内可高亮 | 表格要有"渲染态编辑"：Tab 跳格、回车新行、菜单增删行列、对齐 |
| 数学块 | `$$` 回车进入输入模式：上方带行号的源码框，下方 "Preview ✓OK 🗑" 实时预览；⌘↩ / ↑↓ / 点别处退出；行内 `$…$` 默认关（Pandoc 规则） | 数学块 = 源码编辑器 + 预览的组合控件；行内数学默认关、规则对齐 Pandoc |
| 行内样式 | 粗/斜/代码/删除/下划线/`==高亮==`/下标 `H~2~O`/上标 `x^2^`/`:emoji:`/HTML 注释都渲染；非标准语法在偏好里开关 | 扩展语法可做但默认关，保持 GFM 纯度 |
| 代码块 | 圆角浅灰底、无语言标签、可开行号；语言在块右下角输入 | Quire 已有（含复制按钮、语言标签） |
| 专注模式 | 非当前段落淡成浅灰；打字机模式当前行锁在窗口中线 | 纯样式 + 滚动行为，原生易做 |
| 文件面板 | 三种：大纲 / 文件树 / **文章列表**（文件名 + 正文前两行摘要）；1.14 新增：侧栏可配置显示隐藏文件、非 md 文件；文件树键盘导航 | Quire 侧栏已是树 + 大纲混合；可补"显示规则"和键盘导航；文章列表视图价值一般 |
| 快速打开 | ⌘⇧O 模糊搜索当前目录文件 | Quire 的 ⌘⇧O 已用作"打开文件夹"，快速打开用 ⌘P |
| 全局搜索 | ⌘⇧F 在侧栏顶部，根目录全文 | 需要自己写扫描器，性能预算化 |
| 字数 | 悬停工具栏显示；点开有字/词/行/阅读分钟；有选区时显示选区 | 状态栏右下角，惰性计算 |
| 复制粘贴 | 默认"复制 = HTML"（给富文本 App），⇧⌘C 复制 Markdown；粘贴 HTML 自动转 Markdown | 与系统剪贴板互通是写作工具的基本功 |
| 导出 | PDF（带书签）/ HTML / 无样式 HTML / 图片；docx、epub、LaTeX 等走 **pandoc**（外部） | Quire 已有 HTML/PDF；PDF 书签、导出图片、pandoc 可选 |
| 主题 | CSS 文件，主题站 100+ | Quire 用 JSON（ADR），不追 CSS；主题站不是目标 |
| 1.14 新增 | 悬浮格式工具栏（选中文字时）、右键样式菜单 | 低成本、对新手友好 |
| 1.13 新增 | MathJax v4、Mermaid 11.13、"Open in Typora" VS Code 扩展、改 Markdown 设置不再重启、源码/混合切换保持滚动位置 | Quire 的 reader/editor 切换已保持位置 |

## 3. 不照搬的地方（有意为之）

- **不用 WebView 渲染正文**（ADR-1）：Typora 的一切都是 DOM，所以表格拖列宽、MathJax 都"免费"；Quire 要在 TextKit 2 上自己做，每项都按性能预算验收。
- **不做 CSS 主题**：JSON 主题是数据，切换 130 ms 不重解析；CSS 意味着 WebView。
- **默认 GFM**：Typora 的 ==高亮== / 下标 / 上标 / emoji 在 Quire 里是偏好开关，默认关。
- **阅读优先**：Quire 的启动、内存、大文件仍是第一指标；M6 每一项都要过 `scripts/bench.sh`，写作功能不能拖慢阅读。

## 4. 给 M6 的优先级（价值 ÷ 成本）

1. 表格就地编辑、图片粘贴 —— 写作里最痛的两件事，Typora 用户最常提。
2. 快速打开 + 全局搜索 —— 把侧栏从"导航"变成"工作台"。
3. 字数统计、专注 / 打字机、悬浮工具栏 —— 便宜、讨喜。
4. 复制 HTML / 粘贴 HTML→Markdown —— 与其他 App 互通。
5. 扩展语法、`[TOC]`、标题编号、SmartyPants —— 开关型。
6. PDF 书签、导出图片、pandoc、CLI —— 外围。
